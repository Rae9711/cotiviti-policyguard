# Source method

PolicyGuard stores concise paraphrases and metadata from public CMS and
governance pages. It does **not** republish complete policy manuals or
licensed CPT descriptors.

## How sources are used

1. Identify an official CMS page or PDF with a clear locator.
2. Capture publication / effective dates and a short paraphrase.
3. Record what the paraphrase is used for in the catalog.
4. Propose a declarative review rule only when claim fields can support it.
5. Abstain when clinical purpose or documentation context is required.

## Source pack

See [`data/source_manifest.csv`](../data/source_manifest.csv) and

## Limitations

Paraphrases can omit nuance. Production use requires licensed content,
credentialed reviewers, and retrospective validation.
